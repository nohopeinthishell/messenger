# Messenger

Учебный проект мессенджера на TypeScript, Vite и Handlebars.

## Функциональность

В проекте реализованы прототипы страниц:

- авторизация
- регистрация
- список чатов
- профиль пользователя
- изменение данных профиля
- изменение пароля
- страницы ошибок 404 и 500

## Технологии

- TypeScript
- Vite
- Handlebars
- PostCSS
- HTML

## Установка

npm install

## Запуск проекта

npm run dev

## Сборка проекта

npm run build
