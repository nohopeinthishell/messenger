# Messenger

Учебный проект мессенджера на TypeScript, Vite и Handlebars.

## Функциональность

В проекте реализованы прототипы страниц:

- авторизация
- регистрация
- список чатов
- профиль пользователя
- изменение данных профиля
- изменение пароля
- страницы ошибок 404 и 500

## Технологии

- TypeScript
- Vite
- Handlebars
- PostCSS
- ESLint
- Stylelint
- EditorConfig
- HTML

## Установка

```bash
npm install
```

## Запуск проекта

```bash
npm run dev
```

## Сборка проекта

```bash
npm run build
```

## Проверка качества кода

```bash
npm run lint
```

Команда запускает проверку типов TypeScript, ESLint и Stylelint.
